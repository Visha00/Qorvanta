# Qorvanta Technologies React Website

A responsive React + Vite company website inspired by the service breadth and section structure of Techasoft, with original Qorvanta Technologies branding, copy, layout and styling.

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code / terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL printed by Vite (usually http://localhost:5173).

## Build for production
`npm run build`

## Customize before launch
- Update `hello@techify.example` and `+91 00000 00000` in `src/App.jsx`.
- The contact form currently opens the visitor's email app using `mailto:`. Connect a backend/API (for example Node/Express, Firebase or Formspree) to receive enquiries directly.
- Update service copy, industries, technology chips and company details to match your actual business.
- The reference website's exact text, logos, images and proprietary assets are not copied. This is an original Qorvanta Technologies implementation covering comparable service categories.
